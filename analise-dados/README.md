## O que este portfólio demonstra

- Tradução de problemas de negócio em perguntas analíticas;
- Integração e transformação de dados públicos;
- SQL com CTEs, agregações, funções de janela, `SAFE_DIVIDE` e regras de negócio;
- Modelagem analítica para consumo em BI;
- Análise exploratória e visualização com Python;
- Documentação de fontes, campos, métricas, limitações e decisões técnicas.

## Stack comprovada neste repositório

**SQL e dados:** GoogleSQL, Google BigQuery, Base dos Dados, modelagem dimensional.
**Análise:** Python, Pandas, Seaborn e Matplotlib.
**BI:** Power BI, modelo semântico em PBIP/PBIX.
**Versionamento:** Git e GitHub.

Tecnologias como PostgreSQL, MySQL, Tableau, Looker Studio e Scikit-learn não são apresentadas como competências principais aqui porque ainda não possuem um projeto demonstrativo neste repositório.
